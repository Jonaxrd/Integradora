Este proyecto analiza automáticamente el hardware de una PC y genera recomendaciones de mejora basadas en el rendimiento del sistema y el presupuesto del usuario.

---

##Funcionalidades

- Escaneo de CPU, RAM, GPU, discos y motherboard
- Generación de archivo `hardware.json`
- Motor de recomendaciones basado en presupuesto
- Generación de `resultados.json`
- Interfaz gráfica con Tkinter
- Visualización de resultados en dashboard web

---

##Instalación de dependencias

Dependencias:
pip install psutil py-cpuinfo GPUtil WMI
